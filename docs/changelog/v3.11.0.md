# v3.11.0 — Image descriptions and scene-aware continuity

Prepared on 2026-10-24 for a unified minor release across the umbrella and all five apps. Publication and production rollout are pending.

- Every Cloud and Desktop image generation, including regeneration, uses text AI first to return validated `{ imageDescription, referenceImageUrls }`. Drawing receives only the visual description and selected supplied references; malformed descriptions do not start image generation and Cloud failures retain normal refund handling.
- Per-image fields and editors use **Image Description**, separate from shared **Art Instructions**. Existing descriptions and queued offline edits migrate safely. The backend retains deprecated `imagePrompt` aliases for installed clients; updated Desktop companions advertise structured-description support.
- Chapter context applies to every keyword/element. Current-scene evidence takes priority, followed by the latest applicable earlier state and older gap-filling facts. Source budgets and last-seen limits favor newer relevant observations.
- Situational equipment is reassessed after combat or changes of activity/setting. Ongoing battles, journeys and established habitual outfits can retain gear; uncertain equipment is omitted without inventing removal, healing or ammunition changes. Saved contexts are preserved until explicitly regenerated.
- Selection requests remain stable across translation refreshes, carrying forward the extension’s 3.10.2 fix. The root deployment commands provide a full test gate and an explicit no-check option.
- The website joins the unified version without product changes.

Rollout: deploy migration `20261024104847_image_descriptions` and the backend before updated extension/dashboard clients. Desktop image generation requires the updated companion. Source releases, Chrome Web Store review, native installer publication and production deployment are distinct rollout stages.

Validation: all five typechecks; backend unit and live context/migration tests; Desktop tests/build; extension tests (separate processes for Bun 1.3.6 stability), UI checks and production build; dashboard and website browser checks.
