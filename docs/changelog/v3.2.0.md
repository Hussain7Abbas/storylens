# Story Lens v3.2.0

**Status:** Unreleased — planned next minor update after the umbrella `v3.1.0` tag. The five apps retain their current package versions until the release is approved and prepared.

## Reader accounts and API

- Split reader and dashboard endpoints into `/api/user` and `/api/admin`, with portal-specific roles and route permissions. One account can have reader access, dashboard access, or both; dashboard access is granted by an administrator.
- Added a dashboard for managing users, roles, permissions, novels, keywords, and runtime configuration. The dashboard now edits translated novel fields and offers **Match translations** for keywords named in only one language.
- Added verification codes for email and password changes, plus reader management of their own text replacements.
- Added compatibility safeguards for installed clients: extension and desktop requests identify their versions, the API can reject releases below a configured floor with HTTP 426, and dated deprecations are checked by backend tests. Existing unversioned clients continue to be served.

## Languages and reading

- Added Arabic and English names for novels and keywords, and descriptions for novels. Reader lists, search, sorting, and highlighting use the selected language. The extension migrates older local records and queued writes, and filters downloaded data locally when offline.
- Added translation matching in the dashboard. Its paired desktop client suggests missing names and likely existing keywords; administrators can save a translation or link, alias, or version a matching keyword.
- Improved chapter character extraction with suggested alias or version parents, including parents found in the same extraction batch.

## Local AI and desktop client

- Added an AI wiki crawler with a reviewable character table in the desktop client. It can save novel and keyword names in the response language through the reader API.
- Added editable novel context, AI prompt settings, context research, and Codex character image generation. Desktop prompt requests can explicitly opt into web search.
- Allowed the paired dashboard to call the desktop client for translation suggestions through the local service, with origin checks and pairing-token protection.

## Website

- Updated account pages for the reader API and portal roles. Email changes have their own page, and password changes use a verification code.
