# v3.12.0 — Chapter covers and keyword fallback

[Version changelogs](README.md)

- Keywords use their first version whenever no chapter range matches, including gaps between versions and chapters after the last finite version.
- Different chapters can generate their own cover at the same time with Story Lens Cloud or the updated desktop companion. Each request returns its own image even when the requests finish out of order.
- Click a chapter cover to see it at full size in the same viewer used by keyword images.
