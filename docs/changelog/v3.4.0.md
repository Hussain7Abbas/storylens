# v3.4.0 — Story Lens Cloud and lenses

**Unreleased.** Implementation is in uncommitted working trees; versions, tags and deployment are unchanged.

- Choose Story Lens Cloud or the free Desktop companion in extension Settings → AI. Existing configured pairings keep Desktop by default. Summaries, suggestions, extraction, selector detection, novel research and images use the selected source. Cloud shows prices and a lens balance; one correction is free and failed provider actions are refunded.
- Sign in or register on the website without installing the extension. Balance shows history, requests and account-scoped notices; Pricing gets its numbers from the API. Request lenses with a WhatsApp/Telegram contact for direct payment with the operator. Lenses do not expire.
- Manage billing requests, trial/admin gifts, Cloud models, feature prices and usage in the dashboard. Billing uses an atomic ledger with idempotent charges, approvals, retries and refunds; website sessions use an HttpOnly API cookie.
- The extension navbar has a balance chip, Sync status, ⋮ menu and Back. Paid AI controls show the coin price. Use AI in the text picker starts off. Trial gifts, admin gifts and purchases celebrate in the main popup, with reduced-motion support. First install opens the website profile for session handoff.
- AI-assisted forms load in a background launcher tab and open after completion or refusal. Arabic names ignore diacritics, and the optional Arabic variant matching remains distinct from whole-word matching.
- API changes are additive: no client floor is raised. The legacy selector route remains for old clients until its dated deprecation cycle (`2027-01-31`). Desktop transport and wiki crawling remain compatible.

Privacy/terms and store disclosures are updated drafts awaiting owner review and a native Arabic review. The paid provider smoke test, production-data migration rehearsal, live extension/account/payment checks and release are still pending.
