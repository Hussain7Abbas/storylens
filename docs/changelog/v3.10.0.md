# v3.10.0 — Editable image prompts and keyword inheritance

Released on 2026-10-21. All five apps share version `3.10.0`.

- Chapter covers retain their AI-written image description. Readers can copy it from a collapsible Image Prompt section; publishers and moderators can edit, save and reuse it for regeneration. Concurrent edits preserve the local draft and require reloading the latest revision.
- Image generation uses an AI-written visual description across Cloud and Desktop. Regeneration reuses an edited description directly. Desktop capability negotiation preserves compatibility with older companions.
- Keyword aliases keep their own values and inherit missing fields from the latest applicable keyword versions. Earlier versions and base fields fill remaining gaps; aliases without an image can inherit a version image.
- Extension and dashboard confirmations use shared modal controls. Extension lookup selectors handle invalid options, and popup error boundaries provide recovery from rendering failures.
- The backend adds an optional chapter image prompt column and compatible API fields. Apply its Prisma migration before serving the updated artwork routes.
- Production database documentation records the VPS migration and daily, verified local backups with seven-day retention. Backup scripts and systemd units are installed separately from API deployment.
- Repository documentation includes the shared Voidra planning records and glossary.

Validation: all five app typechecks; backend, extension and Desktop tests; dashboard browser tests; extension and Desktop builds; chapter prompt editing checks in English and Arabic at desktop and mobile sizes.
